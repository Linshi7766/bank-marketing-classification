## Research Findings
- 推荐数据文件：`Dataset/bank+marketing/bank/bank-full.csv`。
- 数据粒度：一行代表一次银行电话营销记录；数据中没有客户唯一 ID。
- 数据规模：45,211 行、17 列，其中 16 个输入字段和目标列 `y`。
- 目标分布：`no` 39,922（88.3%），`yes` 5,289（11.7%），存在明显类别不平衡。
- 真正的空值数量为 0，完全重复行数量为 0。
- 字符串哨兵值 `unknown`：`job` 288、`education` 1,857、`contact` 13,020、`poutcome` 36,959。
- `pdays=-1` 共 36,954 行，表示此前未联系，不应简单当作普通缺失值删除。
- `duration` 在 `yes` 组均值约 537 秒、中位数 426 秒；在 `no` 组均值约 221 秒、中位数 164 秒，预测力很强。
- `duration` 只有通话结束后才知道。如果研究问题是“通话前预测客户是否购买”，它构成高风险信息泄漏。
- 数据来自葡萄牙银行 2008-2010 年电话营销活动，适合教学，但不能直接推广到当前中国客户。

## Technical Decisions
| Decision | Rationale |
|----------|-----------|
| `unknown` 默认保留为独立类别 | 它是原数据的业务状态而非 pandas 空值；全部删除会造成大量样本损失 |
| 同时报告真正空值与 `unknown` 计数 | 既满足不完整数据检查，也体现对数据语义的理解 |
| 主要模型删除 `duration` | 更接近通话前预测场景，避免用事后信息获得虚高结果 |
| 额外比较保留 `duration` 的模型 | 将数据泄漏转化为报告亮点，展示对模型边界的理解 |
| 采用分层训练测试划分 | 保持少数类 `yes` 在训练集和测试集中的比例 |
| 除准确率外报告混淆矩阵、precision、recall、F1 | 准确率在 88.3%/11.7% 不平衡数据上可能误导 |
| 使用逻辑回归和随机森林 | 易解释、运行快，并能形成基线与非线性模型对比 |
| 数据处理设计已确认 | 逐项覆盖数据量、空值、重复值统计与删除要求；`unknown` 保留并解释 |
| 可视化与建模设计已确认 | 4 张数据图；逻辑回归与随机森林；分层划分、平衡权重、混淆矩阵、泄漏对照与前 5 条预测 |
| 报告与答辩设计已确认 | 模板内扩展数据、图表、模型、泄漏对照与预测；答辩按 3-5 分钟主线准备 |
| 采用 `.py` 作为现场运行载体 | 单文件分段清晰、一键运行稳定，比 Notebook 更不易在答辩时出现执行顺序问题 |
