2. 主结果是否采用删除 `duration` 的无泄漏模型？

## Decisions Made
| Decision | Rationale |
|----------|-----------|
| 使用 `bank-full.csv` | 45,211 条数据、分类标签明确、不是 sklearn 内置数据 |
| 采用方案 B 简化版 | 兼顾高分完整性与机器学习初学者的答辩可解释性 |
| 使用逻辑回归 + 随机森林 | 一个简单基线、一个主要模型，避免模型过多难以答辩 |
| 不做交互网页和复杂调参 | 明天下午前需完成，优先保证代码、报告和现场运行稳定 |
| 固定随机种子 | 保证报告结果与现场运行一致 |
| 现场代码采用单个分段清晰的 `.py` 文件 | 一键运行稳定，便于在 VS Code 中逐段讲解 |
| 报告与答辩设计已确认 | 覆盖模板全部栏目，并控制在本人能够解释的范围内 |
| 设计文档已由用户通过 | 可以进入详细实施与验证阶段 |
| 使用 unittest 做核心函数与集成验证 | 不新增测试依赖，确保每一步结果可检查 |
